DiagCore - Comparatif local des interpréteurs

Incident fictif : accès impossible à un dossier partagé. 100 questions inédites, dont 20 à rejeter. Les 60 phrases d'entraînement sont différentes des questions testées. Aucune donnée n'est transmise à une API d'IA ; ce banc télécharge cependant les bibliothèques JavaScript publiques lors de son chargement. Pour un déploiement hors ligne, héberger les bibliothèques dans le projet.

Les bibliothèques officielles Fuse.js 7.5.0 et MiniSearch 7.2.0 sont chargées depuis un CDN pour cet essai. Le chargement NLP.js depuis ESM est expérimental : un échec de chargement signifie « non testé », jamais « mauvais score ». Les seuils sont des réglages initiaux, pas une optimisation scientifique.
